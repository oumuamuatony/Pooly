# Pleos 에뮬레이터 안에서 픽업 테스트

현재 실행 중인 Pleos 에뮬레이터의 **함께가기 시연** 앱에서 시험합니다. 브라우저 조작실을 열 필요가 없습니다. 원래 차량 앱 UI에 에뮬레이터용 테스트 설정만 추가했습니다.

## 바로 사용하기

1. 에뮬레이터에서 **함께가기 시연** 앱을 엽니다.
2. 앱 오른쪽 위 **에뮬레이터 테스트 → 새 테스트 약속 만들기**를 누릅니다. 가상 친구 지연·현준이 있는 약속이 만들어집니다.
3. **앱으로 돌아가기 → 경로 확인 → 출발하기**를 누릅니다.
4. 에뮬레이터 GPS가 자동으로 재생되고, 가상 친구가 픽업 장소로 이동 중인 상태로 바뀝니다. 앱의 지도와 위치 공유는 실제 Pleos FusedLocation SDK를 거칩니다.
5. 픽업 장소에서 위치 재생이 멈추면 앱의 **픽업 장소 도착 확인**을 누릅니다. 가상 친구가 탑승 확인을 보내면 운전자의 **탑승 완료**를 누릅니다.
6. 다음 구간이 자동으로 재생됩니다. 두 명을 태운 뒤 목적지에서 **주차 완료 → 이동 종료**를 확인합니다.

테스트 설정에서 위치 자동 재생과 가상 친구 자동 응답을 각각 끌 수 있습니다. 친구 상태를 직접 바꾸거나, 위치 재생을 일시정지·재개하고 1·2·4배 속도를 고를 수도 있습니다. 내장 내비를 보고 있다면 하단 앱 메뉴에서 **함께가기 시연**으로 돌아와 테스트 버튼을 누릅니다.

## 새로 실행할 때

Pleos 에뮬레이터를 켠 뒤 프로젝트 루트에서 실행합니다.

```sh
bash together/scripts/start-demo.sh
```

스크립트가 시연용 앱을 설치하고 임시 서버가 준비되면 에뮬레이터의 앱을 직접 엽니다. 새 임시 서버에 연결하도록 **시연 앱만** 이전 임시 로그인과 저장 상태를 초기화합니다. 일반 함께가기 앱과 기존 8765 서버의 개인 약속에는 영향을 주지 않습니다. 사용 중인 서버 포트를 발견해도 자동으로 종료하거나 재시작하지 않습니다.

## 시뮬레이션 범위

- 가상 친구 두 명의 수락·준비·탑승 확인은 시연 데이터입니다. 실제 연락처나 위치를 사용하지 않습니다.
- 운전자 출발·도착·탑승·주차·종료 확인은 사용자가 차량 앱에서 직접 합니다.
- 운전자 위치를 서버에 직접 만들어 넣지 않습니다. 저장한 도로 좌표 → 에뮬레이터 GPS → Pleos FusedLocation → 앱의 기존 위치 공유 서비스 순서로 전달합니다.
- 재생 경로는 건국대 → 성수역 → 뚝섬역 → 서울숲으로 고정되어 있습니다. 다른 장소로 약속을 수정하는 시험에는 고정 경로 재생을 끄세요.
- OSRM 경로와 OpenStreetMap 도로 자료를 저장해 재생합니다. 실시간 교통·정차 가능 여부를 판정하지 않으며, 내장 내비가 선택한 경로와 다를 수 있습니다. 출처는 `seongsu-road.json`에 있습니다.
- 일반 앱에서 위치 공유가 시작되면 시연 서버가 GPS 제어를 해제합니다. 실제 차량에서는 이 테스트 설정을 켤 수 없게 제한했습니다.

## 내장 내비 배경 지도 문제

2026-11-08 확인 결과, 함께가기의 경로를 취소하고 내장 내비만 다시 실행해도 배경 지도가 비어 있습니다. 내장 내비가 불러오는 `connect_empty` 스타일은 HTTP 200으로 응답하지만, 바탕·해안선·두 개의 slot만 있고 도로·건물 레이어가 없습니다. 공개 NaviHelper에서 이 내장 스타일을 교체하는 API는 확인되지 않았습니다. 내장 앱의 설정 또는 지도 리소스 문제로 범위를 좁혔으며, 복구한 것으로 표시하지 않습니다.

앱 자체의 OpenFreeMap 지도는 에뮬레이터 안에서 표시되고 위치 공유도 재생됩니다. 이를 내장 내비의 지도 복구로 혼동하지 마세요. 계기판 속도·기어와 내장 내비의 위치 이동도 GPS 위치 재생만으로 검증됐다고 보지 않습니다.

상세 근거: `../verification/oem-map-diagnosis.md`.

## 검증

`InEmulatorTest`가 외부 브라우저 없이 네이티브 테스트 설정, 차량 앱 출발 버튼, 자동 위치 재생, 실제 FusedLocation 수신과 서버 기록, 가상 친구 응답, 운전자 수동 탑승, 일시정지·재개를 확인합니다. Android 시연 APK를 대상으로 직접 실행하여 일반 앱을 제거하거나 개인 데이터를 초기화하지 않습니다. 기존 웹 조작실 파일은 보존했지만 실행에 필요하지 않습니다.
