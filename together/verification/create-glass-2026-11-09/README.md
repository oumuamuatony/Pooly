# 일정 만들기 패널 수정 검증

- 목적지 입력으로 변경하고 별도 도착지 변경 행을 제거했습니다. 출발 위치는 현재 위치를 사용합니다.
- 생성 패널을 오른쪽 상단으로 이동하고 내비 오른쪽 조작 영역을 확보했습니다.
- 입력 영역은 흐름 배치와 스크롤을 사용하고, 저장 버튼은 하단에 고정했습니다.
- Android Window의 배경 흐림과 반투명 테두리·하이라이트를 적용했습니다. 흐림 미지원 환경에는 더 진한 배경색을 사용합니다.
- 목적지 변경 및 저장, 현재 위치 출발, 일행 5명, 6주 달력, 입력 및 뒤로 가기, 생성/이동 패널 전환을 실행 중인 Pleos 에뮬레이터에서 확인했습니다.
- 저장 검증용 일정은 취소했고 기존 시연 일정과 가상 친구 일정은 보존했습니다. 개인 서버와 시연 서버는 재시작하지 않았습니다.
- 일반/시연 APK를 다시 빌드하여 설치했습니다. APK 내부 UI 파일과 현재 소스가 일치합니다.

최종 화면: `create-glass-final.png`
검증 상태: `verification.json`
빌드 결과: `build.log`

실차 동작은 검증하지 않았습니다. 기존 내비 지도 바탕 및 차량 위치 이동 문제는 이번 UI 변경의 해결 범위에 포함하지 않았습니다.

배경 흐림 API: https://developer.android.com/reference/kotlin/android/view/Window#setBackgroundBlurRadius(kotlin.Int)
