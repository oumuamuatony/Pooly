# 오른쪽 상단 패널과 가상 친구 추가

- 이동 패널만 오른쪽 상단으로 옮겼다. 일정 생성 패널은 기존 왼쪽 배치를 유지했다.
- 실제 Pleos 에뮬레이터에서 이동 패널 창이 [1694,145]–[2394,392]에 표시되는 것을 확인했다. 왼쪽 회전 안내와 맨 오른쪽 지도 조작 버튼 영역은 비워뒀다.
- 일반·시연 앱 APK를 다시 빌드하고 데이터 삭제 없이 업데이트 설치했다.
- 실행 중인 시연 서버의 전용 DB에 Store의 등록·초대·참가 로직을 사용해 Max/Kelly/Jeff를 추가했다. 시연 서버는 고정 계정만 반환하므로 일반 HTTP 회원 등록으로 다른 인물을 만들 수 없어, 프로세스와 DB 경로·운전자 세션을 검증한 뒤 해당 DB에만 적용했다. 적용 전 SQLite 백업을 backups에 만들었다. 개인 DB는 열지 않았다.
- Max는 성수역 3번 출구 픽업, Kelly는 뚝섬역 8번 출구 픽업, Jeff는 도보 합류로 설정했다. 세 사람 모두 참가 수락 상태이며, 픽업 두 사람은 장소 대기 상태다.
- ‘가상 친구 픽업 테스트’ 약속을 출발 전 상태로 준비했다. 현재 앱 홈에서 ‘Max님 외 2명’ 카드의 ‘출발하기’를 누르면 된다.
- 기존 지연/현준 약속은 near·재생 중지 상태를 유지했다. 시연 서버와 개인 서버는 재시작하지 않았다.

`upper-right-panel.png`는 실제 내비 위 위치 검증 화면, `test-users-home.png`는 현재 가상 친구가 추가된 홈이다. `seed-result.json`, `panel-check.json`, `final-state.json`에 확인 결과를 저장했다.

시연 서버의 데이터는 임시 DB에 저장된다. 서버 자체를 종료·재시작해 초기화한 경우 `together/scripts/seed-demo-friends.py --pid <현재 시연 서버 PID>`로 다시 준비할 수 있다. 이 스크립트는 개인 서버나 일반 DB를 대상으로 실행되지 않도록 검사한다. 등록 계정의 인증 토큰은 출력하거나 결과 파일에 저장하지 않는다.
