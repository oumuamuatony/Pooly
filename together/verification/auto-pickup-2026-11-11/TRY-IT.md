# 자동 승차 시험 방법

1. 휴대폰 초대 웹에서 약속에 참가하고, 픽업받는 사람이 자신의 픽업 장소를 정합니다.
2. 내 정보 → 내 좌석 설정에서 자동 적용을 켜고 열선/통풍 단계를 저장합니다.
3. 차량 앱에서 해당 여정을 출발하여 Pleos 내비 안내를 시작합니다.
4. 운영 기본값에서는 내비 현재 위치가 픽업 위치 80m 안에 있어야 합니다. 시연 서버를 `POOLY_PICKUP_REQUIRE_PROXIMITY=0`으로 시작한 경우 GPS 검사는 생략합니다.
5. 공식 콘솔 Convenience → Seat Occupancy에서 동승자 좌석을 Empty → Occupied로 바꿉니다. 문을 열 필요는 없습니다.
6. 새 착석이 감지되면 즉시 승차와 좌석이 연결되고 다음 픽업/목적지 안내가 요청됩니다. P단·속도·2분 제한·3초 대기는 승차 조건이 아닙니다. 개인 설정의 실제 적용은 별도로 P단 정차를 확인하며, 주행 중이면 좌석 제어를 건너뜁니다. 콘솔 브라우저는 열어 두어야 DDS 신호가 전달됩니다.

처음부터 Occupied인 좌석은 새 승차로 처리하지 않습니다. 같은 관찰에서 두 좌석이 바뀌거나 센서를 신뢰할 수 없으면 기존 수동 탑승 확인 흐름을 사용합니다.

좌석 각도는 해당 차량·좌석이 메모리 기능을 지원하고 사용자가 그 차량에 저장한 메모리 번호를 지정한 경우에만 복원합니다. 차량에 자세를 먼저 저장한 후, 승차 이후 웹 설정에서 해당 차량의 번호를 선택합니다.

기존 에뮬레이터 지도/GPS 문제 때문에 자동 시험은 픽업 좌표만 통제했습니다. 실제 차량·실제 GPS 근접 인식 시험이 끝났다는 의미는 아닙니다.
