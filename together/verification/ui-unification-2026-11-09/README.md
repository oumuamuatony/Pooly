# Pooly 차량 UI 수정 검증 — 2026-11-09

일반·시연 APK를 빌드하고 기존 설치에 업데이트했습니다. 개인 서버와 시연 서버는 재시작하지 않았고 개인 데이터는 초기화하지 않았습니다.

## 실제 에뮬레이터에서 확인한 항목

- 별도 목적지 검색 화면에서 저장 장소와 실제 내비 최근 목적지 표시, 결과 선택 및 초안 반영.
- 왕십리역 좌표(37.5615, 127.0377)를 일정에 저장. 계획 중 경로 요청은 0회. 출발 후 동일 좌표가 내비 목적지로 전달되어 안내되며 재선택 절차가 없음.
- 일행 추가 화면에 등록된 친구만 표시. 참가자 선택 화면에는 검색·새 친구 등록 입력 없음.
- 홈·주행 기록 상단 탐색과 전체 폭 여정 화면. 지도 영역과 함께가기 문구 제거.
- 일정·검색·친구 선택 및 안내 창에 실제 Android 배경 흐림 적용. 친구 선택 뒤의 중복 입력 화면 제거.
- 출발 후 18.883초 동안 시작 모달과 기존 15초 테스트 알림이 뜨지 않음.
- 필요한 알림을 검증용으로 직접 표시해 1.2초·3.5초 시점의 검정 막대 감소와 7.9초 시점 자동 닫힘 확인. 반복 표시 후에도 창은 오른쪽 상단 [1694,145]–[2394,392] 유지.
- 일반·시연 APK의 웹 파일과 Gleo 스키마가 현재 소스와 바이트 단위로 일치.

## 정책 테스트와 확인 범위

`node test-notices.cjs` 통과: 시작 시 10분 이내 알림 억제, 10분 경계 통과 알림, 중복 억제, 오래된 ETA 및 다른 일정 무시, 도착 상태 전환, 필요한 알림만 표시.

10분 경계 통과는 입력 ETA를 바꾼 정책 테스트이며 실제 주행/GPS 이동 검증은 아닙니다. Android 통합 테스트 APK는 컴파일만 했고 테스트 전체를 실행하지 않았습니다. 내장 내비의 배경 지도가 보이지 않는 기존 문제를 이 UI 변경으로 해결했다고 주장하지 않습니다.

카카오 키가 없어 전국 장소 검색은 아직 사용할 수 없습니다. 현재 결과는 저장 장소와 내비 최근 목적지입니다. 검색 API 연결은 준비되어 있으며 키 설정 후 실응답 확인이 남아 있습니다.

위치 공유가 꺼져 있어도 내비 뒤에서 앱이 멈추지 않도록 안내 동기화 서비스가 동작합니다. 이 서비스는 GPS를 수집하지 않습니다. 위치 공유는 기존 동의 흐름을 따릅니다.

검증용으로 만든 일정 두 개는 취소했고 기존 여정 화면으로 복귀했습니다. 기존 시연 일정의 상태와 개인 서버는 유지했습니다.
