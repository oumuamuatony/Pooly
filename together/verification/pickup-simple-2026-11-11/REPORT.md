# 승차 판정 간소화 — 2026-11-11

## 현재 정책
- 기본 운영: 현재 픽업 대상 + 내비 일정 일치 + 새로운 동승자 착석 + 최근 내비 위치 80m 이내.
- 시연: 서버 `POOLY_PICKUP_REQUIRE_PROXIMITY=0` 설정 시 GPS·거리 검사만 생략. 기본값은 1.
- P단·속도·2분 매칭 제한·3초 유지 대기를 승차 조건에서 제거. 별도 도착 상태로 전환하지 않아도 주행 중 단계에서 바로 승차 기록.
- 현재 픽업 순서, 운전자 권한, 운전석 제외, 기존 점유 제외, 중복 기록 방지, 신뢰할 수 없는 좌석 신호 제외 유지.
- 한 스냅샷에서 여러 새 좌석이 발견되면 자동 추정 보류. 대기 구간을 없앴으므로 연속해서 도착하는 서로 다른 센서 이벤트까지 동시 착석으로 묶지는 않음.
- 운영 모드에서 멀리 있을 때 관찰된 착석을 나중에 근처에 왔다고 새 승차로 재해석하지 않음.
- 시연 여부는 서버 정책. 클라이언트 evidence의 skip_proximity 값으로 우회할 수 없음.
- 좌석 개인 설정의 실제 SDK 제어는 기존 P단 정차·점유 검사를 유지. 승차 기록·다음 경로와 별개이며 주행 중이면 제어를 건너뜀.

## 시연
1. 출발 전 콘솔 Passenger 좌석을 Empty로 둠.
2. 차량 앱에서 픽업이 있는 일정을 출발, 내비와 네이티브 감시가 연결되도록 잠시 기다림.
3. 콘솔의 Convenience → Seat Occupancy → Passenger → Occupied 선택.
4. 현재 픽업 순서의 사람에게 좌석이 연결되고 다음 안내 요청. 또 다른 사람은 별도의 비어 있던 동승자 좌석 사용.
5. 시험 후 좌석을 Empty로 복구. 콘솔 탭은 DDS heartbeat를 위해 열어 둠.
