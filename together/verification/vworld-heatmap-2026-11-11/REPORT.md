# 브이월드 검색 · 키보드 고정 · 휴대폰 픽업 히트맵

## 구현
- 서버 PlaceSearch를 브이월드 검색 API 2.0으로 연결. 장소(PLACE)와 주소(ADDRESS/ROAD 또는 PARCEL)를 함께 검색, EPSG:4326 좌표로 정규화해 단일 결과 목록 반환.
- 제공된 링크의 지오코더는 단일 주소→좌표용. 결과 목록에는 동일 제공자의 검색 API 사용. 지오코더 결과를 별도 캐시/DB로 수집하는 기능은 추가하지 않음.
- 지역·검색어 일치도를 고려한 정렬과 ID 중복 제거, 잘못된 좌표 제거, 일부 API 실패 시 성공 결과 유지, 오류/키 도메인/한도 안내 추가.
- 개발키는 together/data/private/search-provider.json (권한 600, 디렉터리 700)에만 보관. 서버 환경변수 VWORLD_API_KEY/VWORLD_DOMAIN 및 POOLY_SEARCH_CONFIG 지원. 웹/APK/배포 ZIP에는 키 미포함.
- 차량 검색 UI에서 브이월드 출처 표시, 결과 선택 시 키보드 닫기, 좌표가 포함된 목적지 선택 유지.
- 내비 위 유리 패널과 Activity 모두 adjustNothing 적용. 패널 크기·위치 고정, 편집 중 줄어든 WebView 높이에 맞춰 전체 화면을 축소하지 않도록 처리.
- 휴대폰 웹 하단 픽업 지도 추가. 성수·건대입구·왕십리, 전체·아침·저녁 필터, MapLibre heatmap 레이어, 가상 집계/범례/예시 표시.
- 픽업 위치 선택 지도에 예시 히트맵 켜기/끄기 추가. 지도 클릭 좌표 선택/저장은 장소 검색 API를 사용하지 않음. 배경지도 타일 네트워크는 기존 OpenFreeMap 유지.
- 차량 내비 위에는 외부 지도/히트맵을 추가하지 않음.

## 검증
- API 테스트 37개 통과 (브이월드 응답 정규화·주소 정렬·중복/좌표 오류·키 미노출·오류/일부 실패·기존 승차/초대/서버 회귀 포함).
- Android 일반/시연/검증 APK 빌드 및 기존 Kotlin 정책 테스트 10개 통과.
- 실제 브이월드 개발키로 성수역 및 서울 성동구 아차산로 100 조회 성공 (live-search-proof.json). 도로명주소의 다른 지역 검색 결과보다 해당 지역 결과가 앞에 표시됨.
- 별도 integration 앱 + 임시 서버59583/DB에서 실제 Pleos 에뮬레이터 소프트 키보드 시험 통과. 키보드 열린 상태에서도 패널 bounds=[1802,145,592,902]와 WebView 배율 동일.
- 같은 시험에서 브이월드 실검색 → 결과 선택 → 일정 폼 목적지 설정 완료. keyboard-instrumentation.log 및 keyboard-sdk.log 참고.
- 키보드/목적지 선택 PNG 저장. 임시 키보드 설정 원복, integration/test 앱 제거, 일반 앱으로 복귀.
- 390×844 휴대폰 화면에서 예시 지도/시간·지역 필터/픽업 좌표 선택/히트맵 전환 및 선택 유지 확인. 가로 넘침 없음. 테스트 viewport 원복.
- 웹 히트맵 데이터는 전부 고정된 가상 집계. 실제 이용 데이터 수집·추천 모델·정차 안전성 판정·위치 추적을 구현했다는 의미가 아님.
- PythonAnywhere 외부 통신/키 도메인 검증과 공개 사이트 배포는 수행하지 않음. 로컬 프로토타입 확인.

## 적용 상태
- 일반 APK 데이터 삭제 없이 업데이트 설치.
- 웹 정적 파일은 기존8765에서 즉시 반영. http://127.0.0.1:8765/phone.html 하단 픽업 지도에서 확인.
- 서버8765는 검색 모듈 지연 로딩 덕분에 재시작 없이 새 코드 적용 확인. 실제 인증 GET /api/places가 provider=vworld와 실검색 결과 20개를 반환. 서버 PID 76068 유지. 기존 시연 설정(auto_pickup_proximity_required=false), 일정 문서 해시와 사용자 수 보존. live-server-proof.json 참고.
