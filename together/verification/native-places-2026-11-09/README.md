# 내장 내비 장소 연결 검증

- 일반·시연 APK 빌드 및 업데이트 설치 완료. 사용자 데이터 초기화, 서버 재시작 없음.
- 입력한 서울역 검색어를 실제 Pleos SearchPlace에 전달했고 내비에서 검색 결과를 확인했습니다. 서버 장소 검색 호출은 0회였습니다.
- 내비에서 서울역 KTX를 목적지로 설정한 뒤 실제 좌표 37.55489166, 126.96985833을 일정 초안에 수신했습니다. 서버 약속의 서울숲 목적지는 저장 전까지 유지됐습니다.
- 픽업 대상으로 고른 Max·Kelly만 하단에 표시됩니다. 선택 해제와 순서 변경 반영, 두 행 표시, 하단 저장 버튼 분리를 확인했습니다.
- Kelly 위치 보기에서 내비의 뚝섬역 8번 출구 검색 결과를 열고 결과 행을 눌러 내장 상세 팝업을 확인했습니다. 기존 내비 목적지 서울역 KTX, 서버 목적지 서울숲, 픽업 장소, 약속 상태는 유지했습니다. 별도 웹 미리보기 창이나 장소 변경 버튼은 없습니다.
- 외부 지도 스크립트 로드와 타일 요청은 0회였습니다.

## 남은 제한

현재 공개 NaviHelper 3.0.5의 전체 클래스와 공식 문서를 확인했으나, 임의 좌표로 지도 중심을 옮기는 API는 확인되지 않았습니다. 따라서 좌표만 있는 픽업은 내비 검색 결과를 열고 결과 행을 한 번 눌러야 합니다. 경로 요청을 위치 보기로 가장하지 않았습니다.

정확한 POI ID가 있는 경우의 POIDetailPopup 요청은 구현·빌드했지만, 이번 에뮬레이터 최근 장소에서 충분히 일치하는 ID를 확보하지 못해 자동 상세 열기는 검증하지 못했습니다.

기존 내비 배경 지도 미표시는 이번 변경에서 해결하지 않았습니다. 실차 검증은 수행하지 않았습니다.
