# 시연 환경 검증

- 일반 서버 8765의 기존 프로세스 PID 44492를 종료하거나 재시작하지 않았음.
- 별도 시연 서버 8766/8767/8768, 독립 패키지 io.pickuptogether.app.demo를 생성함. 두 친구는 실제 연락처가 아닌 가상 프로필임.
- 기존 차량·휴대폰 디자인을 공유하고 별도 조작실을 추가함.
- 서버 검사 18개 통과. 각 친구의 인증 분리, 초대 수락, 시연 초기화, 픽업 정지, 외부 출처 차단, 개인 앱 공유 보호의 패키지 구분을 확인함.
- Android 시연 빌드와 lint 통과. 실제 Pleos 에뮬레이터에 설치함.
- 별도 GPS 재생 검증에서 Pleos FusedLocation 좌표가 변하고 기존 JourneyService가 주행 위치를 서버로 전송했음. 기록 거리 375.54m. 상세: demo-location-runtime.json. 운전자 위치를 서버에 직접 생성하지 않았음.
- 내장 내비 연결·경로 요청은 됐으나 NaviHelper 현재 위치가 37.4127212,127.094681에 머무름. 올바른 NMEA를 함께 주입해도 이 실행에서 내비 이동은 확인하지 못함. 이 결과를 SDK의 일반적 지원 불가로 해석하지 않음.
- 내비 재기동 중 숨겨진 시연 Activity가 복귀하며 발생한 onResume 오류를 수정함. 이후 재설치와 복귀를 확인함.
- 2026-11-08 사용자 승인 후 시연 서버만 재시작하여 GPS 시간 형식 및 패키지 접두사 구분 수정을 적용했음. 일반 서버 PID 44492 유지, 새 시연 서버 PID 53276.
- 시연 앱의 이전 임시 인증을 초기화하고 새 가상 약속에 연결했음. 원래 앱의 인증과 개인 약속은 초기화하지 않았음.
- 조작실의 차량 출발·위치 재생 버튼으로 GPS → 실제 Pleos FusedLocation → JourneyService → 서버 기록이 연결되는 것을 확인했음. 재생 중 연결 유지, 위치 변화, 기록 증가를 확인함. 상세: demo-restart-runtime.json.
- 일시정지 후 좌표 유지와 재생 재개 후 위치 변화를 확인했음. 두 휴대폰의 별도 인증으로 친구 상태와 운전자 위치가 동기화되는 것을 확인함. 상세: demo-restart-controls.json.
- 검증 후 시연 약속을 출발 전 상태로 되돌려 즉시 사용할 수 있게 했음. 내장 내비 차량 마커 미이동은 여전히 미해결임.
- 일반 앱, 개인 약속 및 원본 디자인 파일을 시연 초기화 대상으로 사용하지 않음.

시연 조작실: http://127.0.0.1:8766/

## 에뮬레이터 내부 테스트로 변경

- 외부 조작실 없이 차량 앱 오른쪽 위의 에뮬레이터 테스트 버튼에서 새 약속·위치 재생·가상 친구 상태를 조작하도록 변경함.
- 가상 친구 자동 응답과 출발 후 자동 위치 재생을 추가함. 운전자의 도착·탑승·주차·종료 확인은 직접 진행함.
- InEmulatorTest를 실행 중인 emulator-5554에서 직접 실행해 통과함. 네이티브 설정창, 차량 앱의 출발 버튼, 자동 GPS 재생, 실제 Pleos FusedLocation 수신과 기록 증가, 자동 친구 탑승 응답, 수동 운전자 탑승, 일시정지·재개를 검증함. 외부 브라우저를 열지 않음.
- 주행 시연용 APK와 테스트 APK만 설치했으며, 일반 함께가기 앱과 8765 서버는 초기화하거나 재시작하지 않음.
- 내장 내비를 단독으로 실행해도 빈 배경을 재현함. connect_empty 스타일의 HTTP 200 응답에 도로·건물 레이어가 없음을 확인함. 상세 근거와 한계는 oem-map-diagnosis.md 참고. 내장 지도와 내비 차량 마커는 복구됐다고 보고하지 않음.
- 정적 검사 중 GleoActivity.kt가 SF_DATALESS 상태로 읽히지 않아, 크기와 수정 시각이 일치하는 이번 작업 전 백업의 내용으로 복구함. 기존 inode는 backups/2026-11-08-unhydrated-source에 보관함. 내용 변경이 아닌 파일 읽기 복구임.
- 첫 내부 테스트 구현의 빌드·lint는 통과했고, 최종 테스트 버튼 배치 변경 APK도 에뮬레이터 실행 검증을 통과함. 최종 lint 재실행은 로컬 파일 읽기 지연으로 완료되지 않아 취소했음. 이를 통과한 검사로 보고하지 않음.
