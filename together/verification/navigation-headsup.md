# 경로 안내 시작 15초 후 내비 위 알림 검증

- 적용 대상: `함께가기 시연` (`io.pickuptogether.app.demo`), Pleos 에뮬레이터 전용.
- 설치 파일: `together/artifacts/together-demo.apk` (해시: `demo-apk.sha256`).
- 앱에서 차량 내비 경로 안내를 시작하면 Pleos NaviHelper 안내 시작 신호를 기준으로 15초 후 시스템 팝업 알림을 한 번 표시한다.
- 새 경로 요청 시 이전 타이머를 취소하고 다시 대기한다. 안내 취소·연결 오류 시 예약된 알림도 취소한다.
- 테스트 문구: “테스트 알림 · 경로 안내 시작 후 15초가 지났어요.” 가상 일행 메시지 형식이며 실제 사람에게 보내지 않는다.
- 알림을 누르면 시연 앱의 에뮬레이터 테스트 설정으로 돌아간다.

## 현재 에뮬레이터 설정

에뮬레이터의 `heads_up_notifications_enabled`가 0으로 꺼져 있어 1로 켰다. 현재 사용자 10의 시연 앱 알림 권한은 허용되어 있다. 별도의 다른 앱 위 표시 권한이나 새 브라우저 페이지를 사용하지 않았다. 일반 개인용 앱과 서버는 변경·재시작하지 않았다.

## 검증 결과

- 최종 APK 빌드 성공.
- 실제 안내 버튼으로 OEM 내비를 실행한 계측 테스트 통과: `OK (1 test)`.
- 안내 시작부터 알림 게시까지 **15006 ms**.
- 14.5초까지 조기 알림이 없는지 확인했고 15초 이후 게시되었는지 검사했다.
- OEM 알림 창 `ai.umos.notification`의 표시된 표면(`HAS_DRAWN`, `shown=true`, `isOnScreen=true`, `isVisible=true`)을 확인했다. 이 OEM 창의 메시지 본문은 접근성 검사에 노출되지 않아 창 표면 검사와 스크린샷을 함께 사용했다.
- 내비가 계속 활성 화면인지 확인했다.
- `navigation-headsup.png`에서 내비 위의 실제 테스트 메시지를 시각적으로 확인했다.
- 알림 채널 중요도: HIGH (4).

이 결과는 현재 Pleos 에뮬레이터에서 시스템 팝업 알림이 내비 위에 표시됨을 검증한다. 내비 내부 위젯 삽입이나 실차 동작 검증을 의미하지 않는다. 배경 지도 미표시 및 OEM 내비 차량 정지 문제는 이 변경으로 해결되지 않았다.

## 다시 확인하기

에뮬레이터의 `함께가기 시연` 앱에서 약속 상세의 `차량 내비로 안내` 또는 출발 버튼으로 경로 안내를 시작한 뒤, 내비 화면에서 15초 기다린다. 안내 시작 후 앱을 다시 열 필요는 없다.
